# 🛍️ NexoraCart

NexoraCart is a full-stack MERN e-commerce platform with secure authentication, product management, cart and wishlist functionality, checkout, order processing, and role-based administration.

## 🌐 Live Demo

- **Frontend:** Coming Soon
- **Backend API:** Coming Soon

## ✨ Features

### 🛒 Shopping
- Responsive e-commerce interface
- Product browsing by category
- Product search
- Product detail pages
- Shopping cart
- Wishlist
- Checkout
- Stock-aware shopping

### 📦 Products
- Product creation, editing and deletion
- Category management
- Pricing and discounts
- Ratings and review counts
- Stock management
- Featured products
- Product images

### 🧾 Orders
- Secure order creation
- Customer-specific order history
- Order details
- Server-side price calculation
- Server-side stock validation
- Order status management
- Admin-controlled order processing

### 👤 Accounts
- User registration and login
- Account-specific cart, wishlist and orders
- Profile and settings
- Customer data isolation

### 👨‍💼 Admin
- Admin dashboard
- Product management
- Order management
- Order status updates
- Backend-enforced RBAC
- Separate customer and admin access

### 🔐 Security
- JWT authentication
- HTTP-only cookies
- bcrypt password hashing
- CSRF protection
- Role-based access control
- CORS allow-list
- Helmet
- Rate limiting
- Request validation
- ObjectId validation
- Server-side price and stock validation
- Environment-based secrets

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- JavaScript
- React Router
- Context API
- CSS

### Backend
- Node.js
- Express.js
- JavaScript
- JWT
- bcryptjs
- Helmet
- CORS
- express-rate-limit
- cookie-parser

### Database
- MongoDB
- Mongoose

🔒 Order Security
During checkout, the backend:
1. Reads current product data from MongoDB.
2. Validates product availability.
3. Validates stock.
4. Calculates the order total.
5. Creates the order.
6. Updates inventory.
Frontend-submitted prices and totals are not trusted.

- Node.js 18.18+
- npm
- Git
- MongoDB or MongoDB Atlas

git clone https://github.com/ManjeetPrabhakarRawat/CodeAlpha_NexoraCart.git
cd CodeAlpha_NexoraCart

cd backend
npm install
copy .env.example .env
npm run seed
npm run dev

PORT=5000
